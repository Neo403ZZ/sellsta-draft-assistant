# 出品アシスト — SELLSTA Draft Assistant

商品URL・仕様・仕入価格を入力し、GPTに渡す作業依頼を生成、SELLSTA下書きの保存後結果を照合する日本語HTMLアプリです。

## この初版で動く機能

- 入力フォーム、端末内の自動保存、履歴、JSONバックアップの読込・出力
- 本体重量と各寸法をそれぞれ1.2倍して梱包後の推定値に換算
- 送料・手数料・利益率から販売価格を概算（還付を含めない）
- 調査・カテゴリ・写真・Item Specifics・HTGオレンジ・Shipping保持・下書き保存・再確認を含むGPT指示文
- requestId付き依頼JSONと、同一依頼の結果JSON照合
- 保存URL、価格、利益率、各確認項目、出典、未確認事項を検査。未確認を完了扱いにしない

**ChatGPTへの送信とSELLSTAの自動操作は未接続です。** 指示文をChatGPT Workに貼り付け、そのGPTがブラウザ操作して返した結果JSONを取り込みます。HTML自体はSELLSTAにログインせず、保存されたことを独立に証明しません。「結果照合OK」は取り込んだ報告の検査です。

## 起動

Node.js 22以上。外部npm依存はありません。

```sh
npm run build
npm test
npm start
```

http://127.0.0.1:4173 を開きます。`dist/index.html` は単体HTMLなので直接開くこともできます（ブラウザによりコピー・保存機能が制限される場合はローカルサーバーを使用）。GitHub Pagesで公開する場合、個人用の実データをソースに埋め込まないでください。

## 利益試算の範囲

アプリの概算式：

```
eBay/広告手数料率 = (落札手数料率 + 広告費率) × (1 + 適用税率)
入金残存率 = (1 - eBay/広告手数料率) × (1 - Payoneer率) - DDP率
販売価格USD = (仕入 + 送料 + その他経費) / (入金残存率 - 目標利益率) / 為替
```

小数2桁で切り上げます。SELLSTA内部の税・手数料計算の完全再現ではありません。固定手数料、海外決済手数料、購入者の売上税等は個別入力・確認が必要です。送料未入力は0とみなしません。最終価格はSELLSTAで保存後に再計算し、還付除外利益率を確認してください。

初期値：Payoneer2%、適用税率15%、DDP13%（試算仮定）、広告10%、目標利益率10%、梱包係数1.2。税率は法定税率を断定するものではなく利用者の試算条件です。落札手数料12.7%は例で、カテゴリ別に確認してください。

## ファイル

- `core.mjs`: 検証・梱包・概算・指示文・結果契約
- `app.js`: ブラウザUIとローカル保存
- `index.template.html`, `styles.css`: UI
- `dist/index.html`: 配布用の単体HTML
- `server.mjs`: ローカル表示用サーバー。API自動実行機能はありません
- `docs/automation.md`: GPT/SELLSTA自動連携を追加する設計
- `test/core.test.mjs`: 誤完了防止と計算のテスト

## データの扱い

入力はlocalStorageに保存されます。ブラウザのサイトデータを消すと消えるため、必要に応じてJSONバックアップを保存してください。パスワード、APIキー、ブラウザプロファイル、実商品の依頼JSONはGitにコミットしないでください。商品説明の仕様値と、配送計算用の推定梱包値は区別します。
